# Hospital360

Hospital360 es un sistema web desarrollado como proyecto final del curso Programación IV.

El sistema tiene como objetivo apoyar la gestión de una clínica mediante el control de usuarios, pacientes, inventario y procesos administrativos.

## Tecnologías utilizadas

- ASP.NET Web Forms
- C#
- .NET Framework
- SQL Server
- Procedimientos almacenados
- Arquitectura en tres capas
- Git y GitHub
- Azure DevOps

## Arquitectura del proyecto

La solución está organizada en tres capas:

- **PL_Hospital360:** capa de presentación.
- **BLL_Hospital360:** capa de lógica de negocio.
- **DAL_Hospital360:** capa de acceso a datos.

## Funcionalidades iniciales

El MVP inicial incluirá:

- Inicio de sesión.
- Registro de usuarios.
- Listado de registros.
- Filtrado de registros.
- Integración con procedimientos almacenados.
